# Data attribution

Source: [PhysioNet / Computing in Cardiology Challenge 2017, version 1.0.0](https://physionet.org/content/challenge-2017/1.0.0/).
ECGs were collected with the AliveCor device and donated by AliveCor for the challenge.

The dataset is provided under the
[Open Data Commons Attribution License v1.0](https://opendatacommons.org/licenses/by/1-0/).
The project code's MIT license does not replace the source data license.
Downloaded raw files stay outside git. Demo waveforms are processed excerpts of selected
public challenge records, with their original record IDs retained for attribution and audit.
They are not newly collected clinical data.

Please cite the original publication:

Clifford GD, Liu C, Moody B, Li-wei HL, Silva I, Li Q, Johnson AE, Mark RG.
AF classification from a short single lead ECG recording: The PhysioNet/Computing in
Cardiology Challenge 2017. Computing in Cardiology, 2017.
[DOI: 10.22489/CinC.2017.065-469](https://doi.org/10.22489/CinC.2017.065-469).

Dataset DOI: [10.13026/d3hm-sf11](https://doi.org/10.13026/d3hm-sf11).
